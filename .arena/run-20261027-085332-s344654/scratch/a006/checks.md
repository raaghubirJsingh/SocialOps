# Acceptance Checks for Haiku

## Task Requirements
- [ ] Exactly one line of text
- [ ] Haiku structure: 5 syllables / 7 syllables / 5 syllables = 17 total
- [ ] Subject: software reliability
- [ ] No extra commentary, no title, no explanation
- [ ] Just the one line

## Syllable Count Verification
Test each line segment for syllable count using standard English pronunciation.

## Contrarian Filter
- [ ] Does NOT celebrate "never fails" or "bug-free"
- [ ] Reflects engineering reality: failures happen, reliability = recovery/monitoring/fallback
- [ ] Technically substantive, not cliché

## Completeness Filter
- [ ] Covers every explicit requirement
- [ ] No implicit requirements missed
